모두변환 개인정보처리방침

시행일: 2026년 10월 10일 · 운영자: 강태양

무료 이용과 개인정보 처리

Mac·iPad·iPhone의 모든 기능은 광고·구독·추가 결제 없이 무료로 제공됩니다. 앱은 광고나 광고 동의 SDK, 인앱 결제 기능을 사용하지 않으며 광고 제공·추적·결제 처리를 위한 개인정보를 수집하지 않습니다. 앱에 별도 계정은 없습니다.

파일과 변환 결과

사용자가 선택한 파일의 사본, 이름, 용량과 최근 이용 기록, 마지막 변환 결과를 앱 저장 공간에 보관합니다. 이 정보는 파일 변환과 최근 목록을 제공하기 위해 사용합니다. 파일 변환은 기기에서 처리하며 파일 내용을 개발자 서버에 업로드하지 않습니다. 원본 파일은 변경하지 않습니다.

글자 인식은 기기의 Apple Vision API로 처리합니다. 운영체제나 클라우드 파일 제공자가 선택한 파일을 내려받는 경우와 사용자가 시스템 공유 대상을 선택한 경우에는 해당 제공자 또는 공유 대상의 처리가 별도로 발생할 수 있습니다. 이 경우 해당 서비스의 개인정보처리방침과 사용자 설정이 적용됩니다.

삭제와 보관

최근 파일의 ‘저장된 사본 삭제’로 앱 내부의 입력 사본과 결과를 삭제할 수 있습니다. 새 변환을 완료하면 앱 내부 이전 결과는 새 결과로 교체됩니다. 원본 및 사용자가 다른 위치에 내보낸 파일은 변경하지 않습니다. 앱 삭제 시 운영체제의 앱 데이터 삭제 정책이 적용되며 다른 위치로 내보낸 파일은 별도로 삭제해야 합니다.

개발자는 사용자 파일과 최근 이용 기록을 서버에 수집하거나 보관하지 않습니다.

외부 고객지원 서비스

개인정보 관련 문의는 외부 서비스인 GitHub의 공개 이슈로 연결됩니다. 사용자가 직접 작성한 문의 내용과 첨부 파일은 공개될 수 있으며 개발자가 문의에 답변하기 위해 확인할 수 있습니다. 비밀번호·개인정보·원본 문서를 첨부하지 마세요.

GitHub 이용 과정에서의 계정 정보와 접속 정보 등의 처리는 GitHub 개인정보처리방침을 따릅니다. 앱이 기기에 보관한 파일과 최근 목록을 GitHub에 자동 전송하지는 않습니다.
