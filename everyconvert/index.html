모두변환 고객지원

Mac·iPad·iPhone에서 파일을 선택하고 가능한 형식으로 변환하는 앱입니다. 모든 기능을 광고·구독·추가 결제 없이 무료로 이용합니다. 원본을 변경하지 않고 기기에 보관한 사본으로 처리합니다.

사용 방법

파일 열기 또는 끌어 놓기로 파일을 가져오세요. 최근 목록에서 파일을 선택하고 출력 형식을 고른 뒤 변환을 시작합니다. 결과는 다른 위치에 저장하거나 시스템 공유로 가져갈 수 있습니다.

여러 파일은 가져온 뒤 한 개씩 변환합니다. PDF 병합은 최근 목록의 PDF를 두 개 이상 선택하고 순서를 지정합니다.

지원과 제한

단일 이미지 저장·PDF 생성, 문서 본문 TXT·PDF, PDF 병합·추출·회전·역순·페이지 이미지, 사진과 스캔 PDF 글자 인식, 기기가 지원하는 미디어 내보내기, WAV 저장, SRT/VTT 자막과 ZIP 묶기를 제공합니다.

모든 형식 사이의 변환을 지원하지 않습니다. HWP/HWPX/DOCX 본문 변환은 원본 배치를 보존하지 않습니다. 암호 문서와 일부 코덱·보호 파일은 지원하지 않으며 글자 인식에는 오류가 있을 수 있습니다.

파일당 최대 512MB, 텍스트 5MB, 단일 이미지 4천만 화소, ZIP 묶기 100MB. PDF 페이지 처리 1,000페이지, 이미지 저장·OCR 100페이지를 지원합니다.

무료 이용 안내

2026년 10월 10일부터 Mac·iPad·iPhone의 모든 기능을 무료로 제공합니다. 배너·전면 광고를 표시하지 않으며, 광고 제거 구매나 구독, 기능을 사용하기 위한 추가 결제가 없습니다.

이전 버전에서 구매한 구독의 관리·취소는 Apple 구독 관리에서 확인할 수 있습니다. 기존 결제의 환불 요청은 Apple 환불 요청을 이용하세요. 무료 전환 안내가 기존 구독의 취소나 환불 처리 완료를 의미하지는 않습니다.

이용약관

파일 보관과 삭제

선택한 파일의 사본과 변환 결과, 이름·용량·최근 이용 기록을 앱 저장 공간에 보관합니다. 파일 변환과 글자 인식은 기기에서 처리하며 개발자 서버에 파일을 업로드하지 않습니다. 클라우드 저장소에서 파일을 내려받거나 시스템 공유 대상을 선택할 때에는 해당 제공자 또는 공유 대상의 처리가 별도로 발생할 수 있습니다.

최근 목록에서 파일을 길게 누르거나 Mac에서 오른쪽 클릭해 ‘저장된 사본 삭제’를 선택하세요. 원본과 다른 위치로 내보낸 결과는 삭제하지 않습니다.

오류와 문의

변환 오류가 나면 형식·용량·암호 여부를 확인하고 파일을 다시 선택하세요. 문의할 때 운영체제, 파일 형식, 화면에 나온 오류를 알려 주세요.
