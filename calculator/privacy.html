기기에 보관하는 자료

사진·영상·파일·메모·폴더 목록·즐겨찾기·브라우저 탭·일반 입력 초안은 기기에 저장합니다. 보관함 파일과 목록은 암호화되며 개발자가 운영하는 서버로 전송하지 않습니다. 사용자가 선택한 사진을 가져오며 사진 앱의 원본을 자동 삭제하지 않습니다.

브라우저와 외부 사이트

방문한 웹사이트와 검색 서비스에는 웹 요청이 전달됩니다. 로그인 유지를 위해 WebKit이 쿠키와 사이트 저장소를 저장합니다. 외부 사이트의 정보 처리는 해당 사이트의 정책을 따릅니다. 비밀번호·인증번호·결제정보로 식별되는 입력칸은 앱의 일반 입력 초안 복원에서 제외합니다. 모든 웹사이트의 상태 복원을 보장하지는 않습니다.

Apple 결제와 구매 권한

월간 자동 갱신 구독과 일회성 평생 이용권은 Apple이 처리합니다. 앱은 StoreKit에서 검증된 구매·만료·환불 상태로 기능 이용권을 판단합니다. 개발자는 결제 카드 정보나 Apple 계정 비밀번호를 받지 않습니다.

Google AdMob 광고

무료 이용 시 Google Mobile Ads와 User Messaging Platform을 사용합니다. Google은 광고 제공·부정행위 방지·분석을 위해 IP로 추정한 대략적인 위치, 기기 식별자, 광고 및 앱 상호작용, 충돌·성능 등 진단 정보를 처리할 수 있습니다. 사진·메모 내용과 보관함 비밀번호는 광고 서비스로 보내지 않습니다. 유료 이용권 활성 시 모든 광고 요청과 표시를 중단합니다.

게시자 광고 개인화와 자체 식별자 기능을 비활성화하며 앱 간 추적 동의를 요청하지 않습니다. 해당 지역에서 요구되는 동의·개인정보 선택 화면을 제공합니다. 보관함 설정의 ‘광고 개인정보 설정’에서 사용 가능한 선택을 변경할 수 있습니다. 선택에 따라 광고가 제한되거나 표시되지 않을 수 있습니다.

Google의 정보 처리에 대한 자세한 내용은 Google 개인정보처리방침과 광고 안내를 확인하세요.

보관·삭제·백업

사용자는 앱에서 자료를 삭제하거나 암호화 백업으로 내보낼 수 있습니다. 내보낸 파일과 암호는 직접 관리해야 합니다. 앱 삭제 시 기기 자료가 없어질 수 있습니다. 외부 사이트의 자료는 해당 서비스에서 관리합니다. 암호를 잊은 자료는 개발자가 복구할 수 없습니다.

고객지원 문의

이메일 문의 시 사용자가 제공한 이메일 주소·문의 내용을 문제 해결과 답변에 사용합니다. 문의 해결 후 불필요한 개인정보의 삭제를 요청할 수 있습니다. 비밀번호·개인 사진·백업 암호는 문의에 포함하지 마세요.

지원 웹사이트

이 페이지에는 별도 광고나 분석 스크립트가 없습니다. 웹 호스팅 제공자는 페이지 전달과 보안을 위해 접속 IP·요청 정보를 처리할 수 있습니다.

변경 안내

처리 방식이 바뀌면 이 페이지에 새 내용과 적용일을 게시합니다.
