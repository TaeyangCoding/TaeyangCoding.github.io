모두의 PDF 앱은 사용자가 선택한 PDF, Office 문서, 이미지와 인증서를 맥 안에서 처리합니다. 앱 개발자의 서버로 문서·본문·이미지·인증서·개인키·암호를 업로드하지 않습니다.

회원가입, 로그인, 광고, 광고 추적, 제3자 분석 SDK, 구독과 인앱 결제를 사용하지 않습니다. 앱이 개발자에게 전송하기 위해 수집하는 개인정보는 없습니다.

사용자가 파일 선택 창으로 허용한 파일을 읽고, 지정한 위치에 결과를 저장합니다. 변환·서명을 위한 임시 파일과 Office 작업 프로필은 작업이 끝나면 제거합니다. 처리 중 인증서와 문서가 메모리에 존재할 수 있으며, 제거가 저장장치의 물리적인 완전 소거를 보증하는 것은 아닙니다.

인증서 서명에 사용하는 이름은 선택한 인증서에서 맥 안에서 읽습니다. 서명자 정보는 결과 PDF의 인증서 서명에 포함되며, 표시 옵션을 켜면 이름이 페이지에도 표시됩니다. 이 결과 파일은 사용자가 선택한 위치에 저장합니다.

인증서 암호는 서명 엔진에 로컬 파이프로 전달합니다. 명령 인자·분석 로그로 보내지 않고 서명을 시작한 뒤 입력란에서 지웁니다. 인증서의 발급기관 신뢰·폐기 상태를 확인하거나 타임스탬프를 받기 위한 외부 통신을 하지 않습니다.

macOS의 프린트, 사용자가 선택한 iCloud·네트워크 저장소·백업 서비스, 시스템 진단 설정에는 해당 운영체제와 서비스의 정책이 적용됩니다. 앱이 문서를 서버에 전송하지 않는다는 설명은 사용자가 선택한 저장소의 동기화까지 끈다는 뜻은 아닙니다.

PDF 열기 암호

호환 열기와 일반 PDF 보호 저장에 필요한 동안 현재 문서 세션의 메모리에 암호를 보관하고 문서를 바꾸면 비웁니다. 암호를 명령 인자나 암호 파일에 기록하지 않습니다. 처리용 임시 PDF에는 해제된 내용이 존재할 수 있으며 작업 종료 시 정리합니다. 메모리나 저장장치의 완전 소거를 보증하지 않습니다.
