개인정보처리방침

업데이트: 2026년 10월 10일 · iPhone/iPad 1.2 및 Mac 무료 정책
운영자: Kang taeyang

iPhone/iPad 1.2 업데이트는 App Store에 제출되어 심사 대기 중입니다. 기존 1.1의 개인정보 처리 방식은 아래 별도 안내를 참고하세요.

1. 앱에서 처리하는 파일

모두보기는 사용자가 선택한 파일을 기기에서 미리 보기 위해 처리합니다. 가져온 파일의 사본, 파일 이름, 크기, 최근 열람 시각을 앱 저장 공간에 보관합니다. 파일 내용과 파일 암호를 운영자의 서버로 업로드하지 않습니다. 입력한 파일 암호는 해당 파일을 여는 처리에 사용되며 별도로 저장하지 않습니다.

2. 광고·구매 없는 무료 앱

iPhone/iPad 버전 1.2와 Mac 버전은 광고 SDK, 광고 동의 화면, 앱 내 구입과 구독을 포함하지 않습니다. 회원가입이나 결제 없이 모든 파일 보기 기능을 이용할 수 있습니다. 개발자는 앱에서 사용자 식별자, 위치, 이용 기록 또는 진단 데이터를 수집하지 않습니다. 선택한 파일, 파일 이름과 암호를 개발자 서버나 광고 서비스로 보내지 않습니다.

기존 iPhone/iPad 1.1을 사용하는 경우

기존 1.1에는 Google AdMob의 홈 배너·전면 광고와 선택적인 일회성 광고 제거 구매가 포함되어 있습니다. 1.2로 업데이트하기 전에는 해당 광고 SDK가 IP 주소에 기반한 대략적인 위치, 기기 식별자, 앱·광고 상호작용, 광고 데이터, 충돌·성능·기타 진단 정보를 광고 제공, 측정과 보안을 위해 처리할 수 있습니다. 비맞춤 광고로 설정되며 IDFA 권한을 요청하지 않습니다. 파일 내용, 파일 이름과 암호는 광고 서비스로 전달하지 않습니다. 필요한 지역에서는 Google UMP 개인정보 선택을 제공하며 기존 1.1의 도움말 및 정보에서 선택을 변경할 수 있습니다. 자세한 안내는 Google 개인정보처리방침을 참고하세요.

기존 광고 제거는 자동 갱신되지 않는 비소모성 일회성 구매입니다. 새 판매는 중단하며, 1.2부터는 구매 여부와 무관하게 광고가 없습니다. 이미 완료한 결제의 환불 신청은 Apple의 문제 신고에서 할 수 있으며 환불 가능 여부는 Apple이 판단합니다. 개발자는 결제 카드 정보나 Apple 계정 비밀번호를 수집하지 않습니다.

3. 저장과 삭제

가져온 파일 사본과 최근 파일 목록은 기기에 저장됩니다. 앱의 파일 메뉴에서 ‘저장된 사본 삭제’를 선택해 사본을 삭제할 수 있습니다. 운영체제의 기기 백업이나 사용자가 선택한 클라우드 파일 제공업체의 처리는 해당 서비스의 설정과 정책에 따릅니다.

4. 고객지원 문의

이메일로 문의하면 발신 이메일 주소와 사용자가 보낸 문의 내용을 문제 해결과 답변을 위해 처리합니다. 문의 해결 후 불필요한 정보는 삭제하며, 삭제 요청은 아래 연락처로 보낼 수 있습니다. 민감한 개인정보가 포함된 파일은 보내지 마세요.

5. 외부 서비스 및 이 웹사이트

파일 선택, 공유, 기기 백업 및 App Store 배포는 Apple과 사용자가 선택한 서비스의 기능을 이용합니다. 이 지원 사이트는 호스팅 제공업체를 통해 제공되므로 사이트 전달과 보안에 필요한 접속 정보가 제공업체에 의해 처리될 수 있습니다. 이 사이트에는 별도의 광고나 방문자 분석 코드를 넣지 않습니다.
