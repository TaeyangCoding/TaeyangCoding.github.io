모두보기 고객지원

파일을 여는 순간부터,
필요한 도움까지.

모두보기는 문서, 사진, 영상, 음악과 압축파일을 확인하는 파일 미리보기 앱입니다.

이메일로 문의하기

처음 사용하는 방법

  1. 앱의 파일 선택 버튼으로 파일 앱에 저장된 파일을 선택합니다.
  2. 또는 다른 앱의 공유 메뉴에서 모두보기로 파일을 엽니다.
  3. 최근 파일 목록에서 가져온 파일을 다시 확인할 수 있습니다.

자주 묻는 질문

어떤 파일을 볼 수 있나요?

HWP·HWPX, PDF, DOCX, XLSX, PPTX, EPUB, 이미지, 텍스트, 영상·음악, ZIP·RAR·7Z 등의 파일을 지원합니다. 파일 버전, 내부 구조와 코덱에 따라 지원 범위가 달라집니다. 모든 파일의 완전한 표시를 보장하지는 않습니다.

암호가 있는 파일도 열 수 있나요?

지원되는 암호화 문서와 압축파일은 올바른 암호를 입력해 열 수 있습니다. 암호를 복구하거나 DRM을 해제하는 기능은 제공하지 않습니다.

원본과 모양이 다르거나 열리지 않아요.

복잡한 문서 서식과 일부 코덱은 표시되지 않을 수 있습니다. 스프레드시트는 저장된 값을 보여 주며 수식을 다시 계산하지 않습니다. 앱 버전, 기기, 운영체제, 파일 확장자와 문제 상황을 이메일로 알려 주세요. 개인정보나 기밀 내용이 포함된 원본 파일은 보내지 않아도 됩니다.

가져온 파일은 어디에 저장되나요?

미리보기를 위해 앱 저장 공간에 사본을 만듭니다. 최근 파일의 메뉴에서 ‘저장된 사본 삭제’를 선택하면 해당 사본을 지울 수 있습니다. 원래 위치에 있는 원본은 유지됩니다.

광고 없이, 모든 기능 무료

iPhone·iPad 버전 1.2부터 배너·전면 광고와 광고 제거 구매를 없앴습니다. 모든 파일 보기 기능을 결제 없이 이용할 수 있습니다. Mac도 광고와 구매 없이 무료입니다.

iPhone·iPad 1.2 업데이트는 App Store에 제출되어 심사 대기 중입니다. 기존 1.1을 사용하는 경우 업데이트 전까지 광고가 표시될 수 있습니다. 광고 제거는 더 이상 판매하지 않으며, 기존 일회성 구매에는 자동 갱신이 없습니다.
